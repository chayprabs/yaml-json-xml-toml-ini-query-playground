# Security

Pluck is a static, client-side application. Document content is processed in WebAssembly inside your browser and is not sent to an application backend.

## Reporting a vulnerability

Please report security issues privately via [GitHub Security Advisories](https://github.com/chayprabs/yaml-json-xml-toml-ini-query-playground/security/advisories/new) or by opening a minimal-reproduction issue without posting exploit details publicly.

We will acknowledge reports as quickly as possible and coordinate fixes on `main`.
